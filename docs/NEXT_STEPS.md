# 接手优先任务与可证伪验收

本页是后续设计建议，不是新实验授权，也不是已冻结新假说。默认先只读工作。

1. **先确认可回答的问题。** 列出“实现修复的局部结论”“自由生成优势”“生物效力”三个不同终点，并为每个终点指定可得的独立证据。不得用最近训练序列作生成正确率金标。
2. **恢复历史链只能补来源，不能重写历史。** 汇总现有27肽逐行证据图，等待作者关于原模型/检查点/生成种子、1000→30→27筛选规则、送样批次、N含义和MIC阈值/聚合方式的事实答复。验收是每条边都有具体文件/时间/ID；没有就维持UNKNOWN，不以论文叙述或提交日期填执行日志。
3. **数据合同优先于新模型。** 若选择监督MIC方向，应明确菌株、培养体系、检测上下限、原生单位、独立来源划分和未知端型处理。固定200不是随机全库样本。两处引用保持空，质量与摩尔单位分开；来源组关联不是独立生物学证明。
4. **最多提出一个新的、非已排除机制的假说。** 先与已有VampPrior/two-stage VAE/LSGM、AR、PBCT/AGCT、Ctrl-G/twisted SMC等逐项比对，说明可区别预测。若只是标准部件重组且没有独特问题证据，停止，不开新种子。

## 若将来获单独授权，实验必须先满足

- 最小对照：原方法、真正可跑且有同等train-only调参机会的AR、候选单组件对照；相同生成时信息，不能暗给真实残基/长度。报告参数、更新、实际计算与调参机会，不能只说同1000步就是公平。
- 预冻结：数据/代码/配置/种子哈希、主指标、失败条件、资源上限、停止规则；实现与独立审计分离；CPU单线程串行并先核活动作业。test37仍封存，不能自动“启封确认”。
- 独立确认：反复使用的dev41不能重置成新验证集；没有未暴露且通过来源/家族/污染隔离的数据，就只给开发性结果，不升级论文主张。
- 最小可证伪命题示例（仅设计模板）：在预先定义的独立来源/家族评价与生成信息条件下，候选相对充分调优AR在一个预锁主指标达到事先规定的效应阈值，同时合法长度、复制/近邻、多样性不劣于预锁容忍度。阈值必须由任务意义与预算事前确定，不能用已看结果倒推；目前没有合格独立评价数据，不能执行这个模板。

## 必须停止的条件

- 无可区分的新机制、无独立评估支持、或有效样本/跨来源覆盖不足：数据/设计NO_GO，不以多模型搜索补。
- 明确限流、鉴权拒绝、许可/隐私边界、资源上限或工程完整性失败：停止，不换凭据/端点绕行。
- 预锁科学门失败：保留全部尝试，不追加seed/预算/样本来救结论。失败不证明整类模型理论无效。
- 新计算不得归因于旧27湿实验；没有相匹配的真实测量就不宣称抗菌效力、毒性、安全性或投稿就绪。

当前最合理的验收输出是“一页可检验问题+证据依赖+一个最小对照设计，或有根据的停止建议”，不是默认续训或投稿稿件。
