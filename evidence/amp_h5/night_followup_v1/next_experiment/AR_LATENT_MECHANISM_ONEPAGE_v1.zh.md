# AMP H5：机制诊断与决定性实验提案（待关键复审；未授权训练）

**判断。** 最小下一步是冻结已有 CE 编码器与 DDPM，只更换为接收 `prefix + terminal + z_t` 的自回归解码器；先检验潜变量是否带来可用增益，再决定是否值得端到端重训。它是机制实验，不能包装成方法新颖性。当前并无证据证明 DDPM 是唯一瓶颈，或更好的重建会带来更好的生成。

**实际机制。** 现有 LSTM 是两层 hidden=64，62,501 参数，学习 `∏ p(x_t | x_<t, c)`：训练用真前缀，生成从 BOS 起用自身已采样前缀，c 为 Free/Amide。PAD=EOS=20，BOS=21 仅作输入；损失只计残基与首个 EOS，分母是实际观察 token 数；48 位序列在窗口内没有 EOS49。自由生成 T=1 全 21 类采样，首 EOS 停止，最多 48 位，空串和截断保留。原 VAE 的 q 接收完整 token embedding、逐残基三描述符 g、九个全局描述符 h；z 是 `[16,48]`，并非单个 16 维向量。解码器是并行非因果卷积，只收 z，训练 CE 与密度项均除以 `B×48`，包含全部尾 PAD；合法前缀 J 是全局选长度的确定性 MAP，不是逐步 EOS 采样。不能将条件于 z 的逐位分解误说成生成序列无相关性。prior flow 用 g 做密度正则，mean-only 加性耦合的 logdet=0；生成没有调用其逆变换。DDPM 以 terminal 为条件生成 `(μ, logσ)`，随后 `z=μ+exp(logσ)ε`，再解码。重建可见目标信息，terminal-only 生成不可见目标序列、真长度、g/h。

**核心可证伪假设。** 在相同自回归模型、预算与推理规则下，训练时保留 x–z 对应关系，能够同时改善 dev 的条件重建和固定 terminal-only 潜变量库的自由生成；若只改善前者，应判为“编码信息可读，但生成增益未证”。只比较新 AR 与旧卷积，会同时改变结构、EOS 语义与损失权重，不能归因单组件。

**固定信息与预算（提议，需一次复审后冻结代码及哈希）。** 只用 train279/dev41，test37 不打开；冻结原 CE q/DDPM，不换 warmup 权重、不改 KL/数据/先验。A/B/C 均 seed222、同批次次序、batch32、Adam .001、clip1、1000 步、最终 checkpoint、零调参机会；观察 token CE、EOS/PAD 与 free-running 全采样规则一致。A/B 共享每步 ε 与初值，B 置换的是完整 z，不置换坐标或 μ/σ 配对；置换种子2422。所有解码训练 CPU 单线程串行，每组内限120秒/外限150秒；历史纯 AR 1000步实测14.293秒，故此为有限 pilot，不能称计算量与原完整 VAE/DDPM相等。预处理上限60秒、全部解码/评分上限120秒，各阶段失败不续跑；自然运行前冻结准确调用数、导出预算和总上限。纯 AR 不为凑账挂无效参数，分别报告冻结、可训练、实际接收信号的参数量与完整历史成本。

**读出与判据（都先锁定，不按结果择指标）。** Dev 用相同已存8组 ε，报告 teacher-forced AA/EOS NLL 与 BOS 起自由重建，主重建量仍为每序列等权准确率；A 另外做 z=0 与同 terminal 整条 z 错配，错配保留边际尺度，z=0 仅作分布外敏感性。A 的正确 z 准确率须比 B 和自身错配均高≥5百分点；这只判信息作用，不判生成价值。生成一律只用 terminal 与已有原 CE 的32个 prior z（16/terminal），A/B/C 用同一预锁 token 随机数库（种子3422/3423）；D 用对应已存结果，不重跑 DDPM。逐 terminal 比较冻结421维 MMD²、dipeptide JS、长度均值差绝对值、合法5–48比例、空串/48截断、重复率、训练集精确复制与最近邻编辑距离。资源升级须 A 在两个 terminal 的 MMD² 与 dipeptide JS 均严格优于 B、C、D，且长度均值差绝对值不增、合法率不降、训练精确复制数及重复率不增；否则保留负结果并停止该路线。这是32样本筛选门，不能宣称显著或稳定总体优势；通过才讨论独立 prior 库/训练种子验证，不自动扩容。

**关键反证与边界。** 仅在生成时对同 terminal 的完整 z 库重新排序不会改变其经验边际，不能作为“z 无用”的证据；有效的配对反证发生在有参考 x 的重建，生成价值看 A/B/C 的固定库对比。z-off 性能下降也可能只是分布外输入。目标导出的 z 下较低 NLL 不是 terminal-only 边际似然，不能直接与纯 AR NLL 排名。8 个 ε 不是8个独立训练或生物重复。现有纯 AR 终点 dev NLL 较早期恶化，尚未证明它已充分调优；pilot 的等机会只限这个预锁预算。以上均为序列统计，不支持抗菌效力或可投稿结论。
