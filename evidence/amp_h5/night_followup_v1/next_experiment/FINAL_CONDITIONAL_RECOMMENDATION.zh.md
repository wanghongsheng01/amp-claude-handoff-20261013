# AMP H5：完整 R/M/S 后的唯一条件实验判断

建议将已冻结的 **CE21 KL warmup、VAE-only 1000 次更新**推进到精确合同和独立预审。这是一次有退出条件的成熟方法探索；本判断不授权启动训练，不自动进入 DDPM 或生成。刚完成的集中独立后审已对评分与分布诊断均给出 PASS，并独立逐序列复算投入门；精确执行合同及运行前负载核验仍是启动前提。

完整 320 条（train279/dev41）的 M 与 8 次 S 共 2880 个预测均有限且完整。固定 dev41 的序列等权非 PAD 准确率为 M=72.2796113%、S8=66.1115798%，差 **6.1680314 个百分点**，超过预锁 5 个百分点投入门。比较采用未舍入的精确计数/真值长度；M 的这一口径不同于既有 497/701=70.8987% 残基微平均。FREE18 的差为 6.0888964 个百分点，AMD23 为 6.2299632 个百分点；无挑选端或随机种子。

当前 dev 的其他结果同样保留：支持氨基酸类别的宏平均召回 M/S8=0.427601057/0.379255661；整串精确为 3/41 与 11/328；长度 MAE 为 0 与 0.140243902。8 次 S 是同一个已拟合模型的 Monte Carlo 读出，不能当作 8 次训练或生物学重复。当前 q 是已学习的对角高斯近似后验，M=decode(μ)，S=decode(μ+exp(logσ)ε)，没有后验 flow；均值处的读出不等于 q 下的期望重建表现。这个区分符合 [Kingma–Welling 的重参数化目标](https://arxiv.org/abs/1312.6114)，但这里使用的离散准确率不是 ELBO 本身。

选择 warmup 的领域先例是 Das 等 2021 年正式发表于 Nature Biomedical Engineering 的 [AMP 生成研究](https://www.nature.com/articles/s41551-021-00689-x)。其[作者稿 §6.1.1](https://arxiv.org/html/2005.11248)给出 VAE β 退火；[官方训练代码](https://github.com/IBM/controlled-peptide-generation/blob/master/train_vae.py)将 β 乘潜变量正则项，[配置代码](https://github.com/IBM/controlled-peptide-generation/blob/master/cfg.py)采用总迭代数五分之一的退火区间。当前仓库默认是 WAE/MMD 配置，而且重建、KL 分母与 H5 不同。因此本轮只借鉴已知日程机制：不搬用论文 β 数值，不称精确复现或新方法。聚合后验密度替换会新增密度拟合问题；AR 正则化是另一项基线充分性问题，本轮不叠加。

唯一候选仍遵循已封存 v2：零基 u=0…999，β(u)=min(1,u/200)。前 200 次更新 β<1，第 200 次为 0.995，第 201 次起为 1；最终 β 不变。固定初始化、批次、前向随机数、学习率、结构、数据、CE/密度项归一化和 J。复用已观察的 β=1 历史对照，因此不称独立复现、相同累计计算或未使用 dev 的确认实验。原 v1 的 500 步构想已被 v2 替代；被撤回的 v3 不参与执行。

成功判定使用 root 在完整 R/M/S 结果前锁定的四项 guard，明确替代 v2 早期文本中“还必须 gap 缩小”的规则。所有条件必须同时成立：

1. 同 dev41、同 8 个已保存 ε 银行，S 的序列等权准确率至少比当前 0.6611157984837004 提高 0.05。
2. M 的序列等权准确率不低于 0.7227961128580324。
3. M 长度 MAE 保持 0。
4. S 的支持类别宏平均召回不低于 0.3792556605509777。

差距缩小本身不算成功，避免 M 退化造成假改善。完整结果任一 guard 未过就停止该 warmup 路线，不换 β、不换种子、不延长步数；缺失、非有限或配对失败保留为不可评价。须同时报告整串精确、编辑距离、逐类别召回、长度/PAD、端别及 train/dev 变化、可用的后验尺度与未加权密度项和实际成本。即使四项通过，也只支持此固定优化日程改善当前重建；仍不能保证先验匹配、生成优势、抗菌活性或投稿准备度，更不能识别 σ、早期 KL 压力或 DDPM 为唯一原因。早期 KL 数值较大不等于梯度主导。

已有分布诊断也限制解释：CE→dev 的长度块仅 FREE 0.000211237、AMD 0.000019760，主要距离留在 AA/二肽块；完整组件 train16→dev 的 2048 次经验参考中，低于 CE 点值的次数分别为 2037 与 697。端间表现不同，且 CE−AR 的三种固定拟合敏感性范围均跨零；这些不是 p 值、总体置信区间或方法等效证据。当前 421 维线性核 MMD 只比较固定特征均值，不能借 [Gretton 等的 MMD 理论](https://jmlr.org/papers/v13/gretton12a.html)扩张成完整序列分布相同。AR 充分性、单训练种子、重复使用 dev 和额外计算机会仍未解决。

更有价值的后续表示核对已有具体入口，而无需现在改变输入：旧 `molecular_representation.py:18,92–95` 将每个孤立 FREE 氨基酸编码为 MolWt/MolLogP/TPSA 并各保留两位小数；`vae_pipeline_formal_v2.py:178–183` 对 residue 做 train-only z-score，对 global 的 z-score 再取绝对值。这里没有核验 L/I 的实际数值是否碰撞，故该碰撞明确待核；也未证明这些表示产生本轮误差。M 在 train/dev 都有 C/D/E/H/M/N/Q/Y 八类零召回，但它们在 train 各有 43–114 个残基支持，不能归因于训练集中不存在这些类别。若 warmup 失败，应先利用已保存错误表核对类别支持、目标编码、位置/PAD及输入到读出的信息保持性，再决定是否提出单独的表示改动；不在此范围加权、扩数据、重分割或换头。

原 CE 正式 E/L/G 永久不可评价、恢复描述门和 PROMOTE=HOLD 保持。test37、原稿和湿实验材料未改；未知 wetlab N 不作推定。本次科学复核仅读取已保存汇总和源码，没有模型、训练、生成、RDKit 重算或新自然数据统计。
