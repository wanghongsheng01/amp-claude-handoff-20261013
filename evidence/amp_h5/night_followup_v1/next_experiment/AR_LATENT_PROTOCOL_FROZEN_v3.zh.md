# AMP H5：AR + latent 决定性 pilot，冻结设计 v3

**设计已冻结，允许后续 high 档制作实现；本文件不授权训练或生成。** 本版一次合并独立审核者 `/root/ar_admission_independent` 的七项必须修改，替代 v2 的相关设计选择。新代码、配置、缓存、共同初值和执行合约须由另一代理核验后才可自然运行；不再安排科学措辞润色。本回合没有模型调用、新随机或新样本。

## 问题与对照

检验 prefix 之外的正确配对 z 是否提供可读取信息，以及在合法 terminal-only 生成中是否比纯 AR 有额外收益。冻结原 CE q 与 DDPM，仅训练新解码器；这是机制与投资筛选，不是端到端修复或方法新颖性。

| 组 | 冻结处理 | 可训练参数 |
|---|---|---:|
| A | 两层 hidden64 LSTM，每步接收 token32、terminal8、z_t16 | 66,597 |
| B | 与 A 相同，只改变训练 x 与完整已采样 z 的对应关系 | 66,597 |
| C | 两层 hidden64 纯 AR，只接收 token32、terminal8 | 62,501 |
| D | 原 CE 卷积/J 的已存输出，不训练、不重新前向 | 历史完整 VAE 1,681,549 |

A/B 同架构、同容量，唯一干预是训练配对。A/C 不声称容量匹配；A/B 的严格对照用于检验配对信息，C 用于纯 AR 效用比较。D 仅历史参照；即使保留其资源比较门，也不把相对 D 的变化归因于单个组件。

## 信息、配对与初值

只用 train279（FREE126/AMD153）及 dev41（18/23），test37 不打开。q 已接收完整目标 token、g/h，可能包含长度信息，因此 q 下重建和条件 NLL 只衡量信息可读性，不是 terminal-only 边际似然。不得换入 warmup 权重。

复用原 CE 的 `posterior_parameters320.npz` 与 reference rows，训练严格只取前279条；开发只取后41条。复用已封存 ε1422…1429。生成仅接受 terminal 和 `ce_checkpoint_recovery_v1/generated_FREE.npz`、`generated_AMD.npz` 中已保存的 decoder-z，各16条；它们来自 conditional DDPM，并非 g 条件 inverse-flow prior。生成接口不能接收真序列、长度或 g/h。权重来源、行ID、terminal、shape、dtype、finite 与 SHA 任一不符即停止，不重编码、不补算、不换库；新 q/DDPM 调用数均为0。

初始化：先用 seed222 创建 C 的共同参数；A 将所有对应 token/terminal embedding、LSTM 权重/偏置及输出层逐字复制，第一层输入权重前40列相同，仅新增16列 z 权重（4,096参数），使用独立 seed7222 的 uniform[-1/8,1/8]。B 完整复制 A。共同块及 A/B 全状态均须摘要相同，不能用“同 seed”替代核验。

每个训练步，用私有 CPU generator seed4422 从完整 train279 q bank 采样 z，A/B 独立重放同一随机轨迹并核每步 digest。B 随后同 terminal 置换整条 `[16,48]` z，再取相同目标批次；不只置换 μ/σ、不重新配目标 ε、不打乱坐标、不在 minibatch 内置换。seed2422 预生成1000步映射：各组随机排列后循环移位一位，形成无固定点双射；映射在训练前封存。组大小1、固定点、跨 terminal 或非双射均预检失败；不回退自身或删行。完整组实际均大于1，即使 minibatch 某端只有一条也不改变规则。有限错配不称严格无信息。

## 49位预测、训练与随机性

新 ABC 统一49预测位，最多输出48个 AA。z1…48取缓存，z49恒零，不能索引不存在的第49列；零向量规则只依赖固定位置，不读真长度。PAD=EOS20，BOS21仅输入。训练目标为 L 个 AA 与首 EOS，恰 L+1 个有效 token；后续 PAD 权重0。CE 为这些 token 的损失总和/有效 token 总数，另报 AA/EOS。当前 train/dev 均无48长序列，所以第49位终止行为仍属外推。

ABC 均 seed222、同一1000步批次表（batch32，保留尾批）、Adam lr.001、betas(.9,.999)、eps1e-8、weight_decay0、clip1、dropout0、最终 checkpoint、零调参。批次表复用已有1000步次序并核身份；不得按开发集选终点或早停优胜权重。三个自然训练臂各仅一次。

Dev 自由重建 BOS 起逐步 argmax，首EOS停止，不采输出 token。A/B 常规读出各为 μ 与8个 q 样本；C 只读一次；A 另读一次 zero-z 和8个错配 q（seed6422，规则同上）。以上28个条件各含41条，分别报告 teacher-forced NLL 与自由重建；teacher forcing 不传入自由重建。主准确率为真实 AA 位置匹配数/L，提前EOS后的缺位记错，先等权8次再等权41条；另报多余长度、长度 MAE 和整串匹配。zero-z 是分布外敏感性检查。

生成 ABC 各32请求，从 BOS 起 T=1 全21类逆CDF采样。共享按 terminal、slot、49位置索引的 uniform bank（3422/3423），停止行吸收、不挪用其他位置随机数。第49位若 EOS 则自然终止；若 AA，不输出第49个残基，记 `cap_nonEOS`，保留已有48AA。D 维持原48/J定义，不伪造其 EOS49，也不把 D 的 cap 与 AR 的未终止率等同。

## 判据与失败分母

重建信息门：A 的 S8 等序列准确率分别较 B 的 S8、A 自身错配 S8 高至少0.05。A/C 的差异完整报告但不称容量匹配因果效应。重建通过而生成不通过，只能得出“信息可读，生成收益未证”。

生成对 dev 对应18/23条分别评价，不合并端别择优。复用冻结421维 biased linear MMD²：length/48、20 AA比例、400二肽比例三块各1/3权重；无带宽、无新拟合。二肽 JS 使用现有 pooled counts、log2、无新增平滑。保留 v2 全部资源门：A 在两个 terminal 的 MMD² 和 JS 均严格优于 B/C/D，并相对每个对照分别满足长度均值差绝对值不增、合法5–48率不降、训练精确复制数和重复率不增。并列、undefined均不能通过严格优于条件；cap_nonEOS 单列，不与 D 混比。

所有请求与状态永久保留。各端率的请求分母固定16；复制使用序列是否出现在全部 train279（另报 sequence+terminal），重复数为完成输出数减完成输出的不同序列数，再以16为率分母；缺失不计为序列或重复项。最近邻另用单位成本 Levenshtein/max(两序列长度)，对全部 train279 取最小值；这是单独的编辑距离，不把既有 NW identity 改名。完成空串长度记0。

不扩展旧特征函数的空串定义。主生成比较要求 A/B/C/D 各32槽完整、非空、canonical。A 空串或失败即升级失败；对照空串、缺失或超时则主比较 NOT_EVALUABLE，均不扩容。缺失时只可列明有效 n 的条件统计，不能据此通过主门。`cap_nonEOS` 是完整48AA截断结果，不是超时，也不是自然终止。提前EOS空串是有效负结果，不能过滤后补采。

一个训练seed、固定 dev41、32个已有 DDPM z 只构成有限投资筛选；8组 ε 不等于8次训练或生物重复。通过不自动授权更大实验，失败不泛化为所有 AR VAE 均无效。AR VAE及其组合已有先例，不据本实验声称新颖、泛化、抗菌效力或投稿就绪。
