# AMP H5：零 ε 预测的解析尺度参照

结论：冻结的 999 点线性 β 日程，按实际 `t=998,…,1` 逆推，若每步 ε 预测恒为零，则终点单坐标标准差为 **220.42280094**。保存 smoke 的坐标标准差为 **215.7608–216.7400**，约为该参照的 **97.9%–98.3%**。这个接近关系只描述尺度，**不证明模型实际预测为零或接近零，也没有识别溢出的根因**。

## 假设与推导

使用 H4 已保存 `SCHEDULE.npz` 的 float32 `alpha`、`beta`，读取后以 float64 标量计算，不重新构造另一条理想精度日程。β 端点约为 0.0001 与 0.02。设初值单坐标 `x∼N(0,1)`；每步新噪声彼此独立，且独立于初值；条件 ε 预测恒为零。实际逆更新于是简化为：

\[
x' = x/\sqrt{\alpha_t}+\sqrt{\beta_t}\,\xi_t,
\qquad V'=V/\alpha_t+\beta_t \quad(t>1).
\]

最后 `t=1` 不加新噪声，故 `V'=V/α₁`。循环从 `V=1` 开始，执行 `998,…,1`。没有执行 `t=0`，所以 `α₀` 不进入该递推；在零预测假设下，实际更新中乘在 ε 预测前面的累计 `alpha_hat` 系数消失。每个 μ 与 logσ 坐标具有相同的解析方差。

独立的闭式交叉核对为：

\[
V_{\rm final}=\prod_{j=1}^{998}\alpha_j^{-1}
+\sum_{t=2}^{998}\beta_t\prod_{j=1}^{t-1}\alpha_j^{-1}.
\]

初始噪声贡献方差为 **24526.16222009**，逆过程新噪声贡献为 **24060.04895210**；总方差 **48586.21117219**。两种计算绝对差为 `8.0e-11`。这里相加的是方差，标准差不能直接相加。
