# AMP H5：等量、完整component训练经验参考

在预锁的等量参考中，CE和MSE生成后验的尾部及logσ均值图差异仍超过多数训练内部参考波动；这一结果收窄了“纯样本量差异”的解释，但不是实现bug或因果机制的证明。CE FREE的位置μ–logσ关联差与训练参考波动重叠，不能将旧相关差单独当作结构异常证据。

分析在已知生成负结果及旧尺度/结构结果后提出，是事后探索。protocol/LATENT_SAME_N_GROUP_REFERENCE_v1.json在本次取样/统计前冻结，经独审27项静态核验，再执行。单线程NumPy耗时11.834秒，零模型/forward/新latent或肽采样，不读live scalar/test；新增随机性只有预锁的component子集索引。

每端生成只有16条；1536维(mu,logσ)中心化经验协方差秩至多15。因此本次不计算全协方差、whitening、W2、投影或收缩，也不把坐标当独立样本。

训练279条由冻结NW70%连通规则形成224个component，并非生物学家族或组内任意两条70%。存在7个跨端component。每次联合选择完整component，使留出恰为FREE16+AMD16；其余参考恰为FREE110+AMD137。不独立抽两端后取union，也不拆组。全部279条都曾参与模型训练，所以这里的holdout只表示统计参考分割，绝不是模型未见数据、dev或泛化验证。

用整数suffix DP计算所有可行完整component子集，再按条件精确等概率回溯；共有488466986509709352862250309225896922个可行子集，每个概率为其倒数。NumPy1.26.4/PCG64 seed20261011固定256次，CE/MSE共享全部索引。生成16与留出16都对同一remaining参考计算指标。不是均匀抽序列或每组相等inclusion概率；此条件设计不能视为无偏的总体抽样。

256次没有重复子集，所有224组都参与DP且没有因大小预先排除；实际inclusion count范围0–64，其中8组这256次未入选。INDEX_SEAL保存所有选组、行号、余参、RNG状态和每组次数。重复参考使用相同训练集和相同生成16，不增加独立生物重复；以下2.5%–97.5%是经验变化区间，不是置信区间、null分布或p值。

因此不能泛称所有相关结构差都是异常：CE FREE位置关联的paired差区间跨0；MSE两个端基也有重叠。CE AMD该位置关联差和四个分组logσ均值图差在此经验参照下仍保留较大偏移。全部预锁指标与所有1024条比较记录已保留，没有按结果删指标、换种子或挑选子集；描述性fraction(delta>0)不是显著性检验。

旧全train参考的32.51%/29.18%等数值保持原样。新分析reference少了完整留出组，分母为110/137而不是126/153，不能覆盖旧结果或把新的范围当更优阈值。真实dev每条序列的latent范围对照为MISSING/NOT_EVALUABLE：当前检查点只保存dev均值重建CSV及聚合monitor，没有dev μ/logσ/z。禁止以重建序列冒充latent，也没有补跑forward。

本结果仍只能定位候选问题：生成后验与训练编码后验存在超出这项训练内部抽样参考的差异；训练后验本身的decoder样本可读性、合法terminal-only native prior路线及实际抗菌活性都未由本次分析解决。原CE E/L/G仍NE，四臂配置不变，64输入v1/v2仅候选准备，后续来源替换须四臂独审完成后新scope。
