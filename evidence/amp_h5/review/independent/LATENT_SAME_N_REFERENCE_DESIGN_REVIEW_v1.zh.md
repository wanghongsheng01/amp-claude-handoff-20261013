# AMP H5 同尺寸 latent 参考分析设计约束

本文件仅审查新增、事后探索的保存数组分析设计；不授权模型前向、改变四臂或改写旧诊断数值。原 CE E/L/G 仍不可评估，PROMOTE HOLD。

每端基生成 n=16。若把 mu/logsigma 拼为1536维，则中心化经验协方差秩最多15；单独768维也一样。train126/153与gen16的协方差、相关结构、均值图误差或范围外比例受到样本量影响。真实有效样本量还可能因同源、训练模型及共享批次而更低。不能将32.5%/29.2%之类匹配坐标训练范围外比例当作 DDPM 实现错误、无效 latent 或统计拒绝率。

建议在新协议中事前固定重复数、一个seed、算法/版本、全部统计量及抽样单位。每次从同terminal训练池无放回抽两个互不重叠的16记录集合 A/B；比较 gen16与A16，以及B16与A16的同尺寸差异。后者是训练经验分布内的有限样本参考，并非证明生成过程可交换、因果归因或拥有多个独立训练重复。反复重抽不会增加生物样本数。保留所有重复和索引，不按生成结果选择统计量或参考子样本。

训练子样本对包含自己的full-train min/max必定不越界，不能据此建立有效的越界基线。若做held-out16对剩余train范围，则FREE/AMD参考规模是110/137，不再是旧表126/153；必须明确不同分母和由此产生的区间宽度差，不能静默合并到原比例。dev逐序列的latent覆盖可以补充，但若没有保存dev posterior，只能标MISSING；均值重建字符串不是latent位置，也不能偷偷新增encoder forward。

同源group若存在可靠、预先冻结的来源，应明确分组规则、terminal跨组关系及权重。如果没有，使用sequence为观察单位并披露同源依赖，不临时猜组。按group抽样会改变有效单位、总序列数或权重，不能在不说明的情况下继续称为相同16序列设计。

优先保持已有可解释汇总，避免不可逆的高维样本协方差。若使用projection、shrinkage或其他正则化，必须仅train拟合、参数与维数预锁、生成样本不参与选择；其统计性质和有限样本误差仍需核验，不能将未经验证的whitening/W2当作创新或已解决瓶颈的证据。

所有新结果单独命名、引用旧已封存数据哈希并列出成本。分析至多提供“与latent匹配瓶颈相容”的有限证据；实际decoder-space标准正态/训练经验后验参照仍需另scope、scalar真实终态及独立执行回执。
