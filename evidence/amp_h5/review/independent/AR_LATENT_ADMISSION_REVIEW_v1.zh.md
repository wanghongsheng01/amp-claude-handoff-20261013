# AR latent 机制实验：一次独立准入复审

**可实现：有条件准入制作冻结实现。可自然运行：当前不准入。** v2 是可证伪的有限机制 pilot，但还不是可执行合约；本意见不授权训练。修正以下项目并由不同代理核验冻结实现即可，不需再做一轮科学措辞评议。本轮仅静态读文件、核对 train/dev 计数和写评审，零模型调用、零新随机、零外部研究。

1. **A/B 的干预成立，但只限“训练配对关系”。** A/B 必须逐字共享初值、批次、优化器与完整已采样 z bank；B 每步置换整条 `[16,48]` z，再取目标批次。禁止在置换后重新配目标 ε、仅在 minibatch 内置换或只打乱时间位置。全 bank 的 terminal 组实为 train FREE126/AMD153，dev18/23；组大小为1时必须在训练前报错停止，不能回退自身、跨端或静默删行。固定点、跨端、非双射均失败；有限无固定点错配仍非严格独立，不能称“完全无信息”。

2. **C 改回 hidden64、62,501 参数；A/B 各66,597。** 这样可将 token/terminal embedding、两层 LSTM 的对应参数及输出层逐字共享，只为 A/B 添加4,096个有效 z 输入权重；同 seed 本身不保证对应块相同，须复制并哈希验证。取消 hidden66 的复杂逐门映射。A–C 不宣称容量匹配，容量混杂由同架构 A–B 控制。D 旧卷积/J 仅历史参照；保留其投资比较门可以，但既非 matched ablation，也不能把相对 D 的变化归因为 z 或单个解码组件。

3. **推荐统一采用48 AA＋第49 EOS判定位。** 新 A/B/C 全部使用49预测位；z1…48取原缓存，z49恒零且不新增参数、不读真长度；禁止读取缓存第49列。训练只掩码残基及首EOS，恰 `L+1`，PAD尾部零权重；CE 分母为实际观察 token 总数，另列 AA/EOS。自由输出第49位仍采全部21类；若非EOS，不输出第49个AA，记录 `cap_nonEOS`；若EOS则为真正终止。共享 uniform 改为逐slot×49，吸收停止不挪用后续位置。当前 train/dev 长度48均为0，因此此修正不改变两集合的观察 token 数；第49位终止能力仍属外推。D 保留原48/J定义，不能伪造 EOS49，也不与新 AR 的 cap 指标等同。

4. **信息路径与缓存必须锁定。** train/dev 使用封存原 CE 的 μ/logσ 与现有8组 ε，校验 checkpoint、行ID、terminal、shape、dtype、SHA；不得混入 warmup。full-target q 可见 x、g、h、长度信息，其 NLL/重建仅回答编码信息是否可读，不是 terminal-only 似然，也不能据此胜过纯 AR。生成仅复用原 CE 两端各16条、已保存的 conditional-DDPM **decoder-z**；生成接口不得接收目标序列、真长度、g/h。现有 train/dev posterior 缓存足够时 q/DDPM 新调用均为0；缓存不符则停止，不临时补算或换库。

5. **主指标和完整分母写成公式。** 重建主准确率用每条真实 AA 位置匹配数/L，提前EOS后的缺位记错，先等权8次、再等权41条；额外列长度误差和完整序列匹配，避免长输出的多余AA被主准确率掩盖。保留 A 比 B及自身错配各≥0.05的门；zero-z只是分布外敏感性。生成复用冻结421维 **biased linear MMD²**：长度/48、20 AA比例、400二肽比例三块各1/3权重，无带宽；JS为现有 pooled dipeptide、log2、无新平滑。锁定最近邻距离算法、归一化及 train279参考，不能把既有 NW identity 改名为编辑距离。

6. **不扩展空串特征，采用保守完整性门。** 所有32请求及状态永久保留，率/复制数/重复数使用固定请求分母；长度均值含完成的空串0。主生成比较要求 A/B/C/D 各32槽全部完成、非空且canonical；A空串/失败使其升级失败，对照空串或缺失/超时使比较 NOT_EVALUABLE，均停止扩容。`cap_nonEOS` 是完成的48AA截断结果，单列率；不得当作超时，亦不得声称自然终止。发生缺失时可报明确标注有效n的条件分布统计，但不得用它通过主门。保留v2全部预定质量门，undefined/并列均不能通过严格优于条件，不补采、不改核、不选ε/指标/终点。

7. **有限成本和运行闸门。** 仅一次 seed222、三臂各1000更新；预处理≤60s，三臂各内限120s/外限150s，全部解码评分≤120s，最终封存≤30s，端到端外限 **660s（11分钟）**，CPU单线程串行，启动前检查H5活跃进程。冻结源码/数据/配置/缓存、共同初始化、1000步批次与置换、ε重放规则、49位uniform、准确调用上限和失败槽位；完整bank按步重放并验digest即可，不必写出1000份大z库。历史纯AR1000步14.293s支持此预算数量级，但不是新实现120s必达的证明；资源失败只记失败，不加时/续跑/减步补齐。以最终checkpoint比较，任一训练未完成1000步不得作等更新数胜负结论。

母题保持为“prefix之外，正确配对z是否提供可读取信息，并给合法prior生成带来额外收益”。只过重建门则结论为信息可读、生成收益未证；全过也只是固定 dev41、32槽、一个训练seed的投资筛选。AR VAE及其混合并不因此产生方法新颖性；不支持泛化、抗菌效力或投稿准备结论。BACKUP_BLOCKED保留。

证据：同名 JSON 绑定本次读过的关键文件 SHA256；既有实现目前仍为48窗口、纯terminal LSTM，不能直接当作上述新合约已实现。本轮没有计费观测，不报告金额；660秒是建议的未来计算预算，不是本轮实耗。
