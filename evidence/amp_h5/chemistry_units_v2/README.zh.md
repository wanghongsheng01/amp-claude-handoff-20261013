“结构通过”仅确认数据库表示的中性共价母体与序列、支持的修饰及分子式相符。自动生成 SMILES 没有证明实验称量物是该纯母体，或说明其盐、结晶水、溶剂、纯度/净肽含量的计量基准。没有材料基准证据覆盖项，因此所有质量浓度记录仍 PENDING。REFUSE 为 0 不代表材料已获认可。

条件字段使用 `µM = µg/ml × 1000 / 母体平均分子量(g/mol)`，不是同位素精确质量。原值、单位、严格大于方向及范围上下端点保留；不把右删失界当作点观测，也不解释未核实的范围/±语义。表中的 `training_admitted` 均为 false。

`CNN_REPRESENTATION_AUDIT.json` 对 8 个条件候选逐一列出不能编码的化学特征。ID1689 含 D 型残基与头尾环化；ID37、4339、4379、4380 有末端修饰，普通作者 CNN 没有相关输入，不能忽略这些差异后声称化学实体可区分。null 末端仍为未知注释；长度100可表示不等于作者训练筛选的长度<100已通过。

## 已冻结的方法

先冻结 `PLAN.json`、代码、合成测试及来源哈希于 `FREEZE.json`，再执行 75 条离线核对。独立复核由另一代理完成，文件位于 `../chem_cnn_audit_v1/`。

逐个 SMILES 检查合法性、单连通组分、电荷、同位素及未指明手性；不移除盐、不中和电荷。独立重建标准氨基酸图，按小写 D 标注反转该残基全部手性中心，支持显式 C 端酰胺、二硫键和标注的头尾主链酰胺环化。独立元素计数检查缩合水、二硫键失氢和端基变化，再与图的平均分子量比对。未支持的化学成分保留 PENDING。

v1 通用全分子互变异构枚举有 41 条达到冻结上限；原代码、原结果和日志完整保留于 `../chemistry_units_v1/`。v2 经独立预审后，只规范中性、无同位素/局部立体标记的精氨酸型胍基质子/单双键位置；强制分子式、电荷、重原子连接、原子手性及局部外原子/键不变。完整立体图必须与独立重建图及所有提供的变体一致。没有扩展为通用互变异构搜索；组氨酸 HID/HIE 未规范，不能把剩余不匹配直接称作化学错误。

作者 16 项合成检查与独立 27 项合成检查通过；实际离线核对耗时约 7.99 秒。软件为现有 RDKit2023.09.5。旧 v1 的计算上限结果不是被删除或改写的负结果。

## 下一次自然训练准入

本批数据尚不准入自然训练。下一步可以复用这些明确产物，而无需重复爬取或盲目训练：

1. 对拟用候选建立逐条材料计量基准证据、测定条件和标签语义清单；无法建立者保持排除/待定。组氨酸互变异构与非标准残基需要单独冻结、独立复核的化学规则，不能在本轮事后扩大。
2. 冻结化学实体表示策略：普通作者 CNN 无法区分同序列不同端基或环化。若新增条件输入，应作为明确的新控制变量；本次只是复刻既有架构。
3. 执行独立保管人的不透明去污染回执流程；当前没有回执，化学核对不等于 train/dev/test 隔离。test37 继续封存，不为此开放。
4. 按临时序列家族和来源合并组检查可用独立样本与匹配测定条件，制定不依赖 test37 的分组验证及精度门槛。现有 3 个可编码候选只来自 2 个来源组，不支持把行数当作独立样本量。
5. 数据准入后再冻结单一方法差异（例如点似然与删失感知似然）、相同编码器/条件/数据/种子/调参机会、CPU 单线程步数和时限、失败规则。Witten 合成吞吐提供预算估算输入，不是自然数据吞吐实测。

不主张生物效力、已证明创新、公平性能优势或投稿就绪。
