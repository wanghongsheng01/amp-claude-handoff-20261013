# 不训练诊断：独立审计意见

**未发现能够解释负结果、且可通过修复恢复的训练/预测实现错误。发现一处独立的缺失值报告错误，已确认不影响模型。** 全程没有优化、自然训练、联网、受保护数据读取或旧文件改写。

实现复核 349/349 通过：log10 原生浓度、训练/评分变换、21 个输入特征与截距、训练折尺度、两种权重、来源组隔离及删失仅训练均一致。所有保存预测由独立公式重建，最大误差 8.88×10⁻¹⁶。响应直接拟合 log10 值，无须在 log10 评分前指数反变换；特征中自然 log 长度是另一项明确的输入变换。点值臂共享全部训练 X 的尺度，与前轮不同，但已经披露。

纯算术诊断 582/582、编码与条件分层 418/418 通过。下列证据属于观测分解，不是因果根因证明：

- 来源组均值之间的方差占点标签总加权方差：µg/ml **90.83%**、µM **71.37%**。尾概率模型误差中的组均偏差平方占 MSE **92.93%**、**84.87%**。数据主要差异和该模型主要误差都集中在组均值层面，但不能据此判定哪种条件或生物机制造成差异。
- 相对训练折点均值，模型预测调整的平方能量超过其两倍标签对齐项，恰好解释此次 MSE 上升。这是恒等式验证，不是特征完全无信号的检验；µM 点 ridge 的对齐项为正，也不足以抵消调整能量。
- 有 **29/79** 个质量点、**32/68** 个摩尔点至少一维组成/长度特征超出对应训练折的坐标范围。单维范围不是联合支持判定，不能证明外推造成错误。
- 在相同折、相同组成与长度输入内，标签离散贡献的经验 MSE 下限分量为 **0.0161394**、**0.0350949**。质量单位存在一个跨 ID 同序列桶；摩尔单位存在一个不同序列同组成桶。该分量远小于模型总 MSE，不能把全部误差归咎于相同输入标签差异，更不能称为已估计的生物噪声。

**报告错误**：µM 点数据中 14 条培养基值为纯空格；旧真值判断将其计为非缺失，正确缺失数为 **14/68**。新诊断以去除首尾空白后的值判断，旧冻结包与初版诊断保留。模型没有培养基输入，也不按培养基完整性筛选，改变这项报告计数不改变标签、特征、权重、分组或预测，因而没有重训理由。

已观测菌株文本与培养基相同的分层仍很小，且其他条件未统一，不能升级为新的独立 benchmark。所有标签已暴露、点报告存在选择偏差；本轮可说明固定模型的错误结构，不能证明表示无信号、尾概率方法普遍失败，或确定未来干预效果。BACKUP_BLOCKED。
