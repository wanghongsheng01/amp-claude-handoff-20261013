# H5 独立科学设计意见：端到端损失对照与 terminal-only AR

状态：**DESIGN_OPINION / NOT_A_FINAL_PROTOCOL**。本意见由独立主张审阅者撰写，不编写作者模型、不运行模型/拟合/采样、不读取test。父任务已授权H5方向；具体目标、训练预算、AR实现与运行门仍须作者协议冻结及独审。本意见不替代运行START，不回写任何H0–H4产物。

结论：有依据开展一次有界的端到端21类头对照，但目前不能把失败诊断简化成“训练目标错了”或“潜变量OOD”。最小新比较为 **CE21完整管线、同容量raw one-hot MSE21完整管线、一个规范terminal-only AR**。原scalar管线及H4 CE+J保持历史参照；不同时去掉g/h、换flow、改latent尺寸、换DDPM、调KL、换scaler再归因一项。

## 1. 已证事实与未证机制

| 命题 | 现有证据及正确边界 |
|---|---|
| scalar整数MSE把类别放在任意有序数轴 | 数学结构成立：类别编号的距离直接进入平方损失，PAD=20与编号19/0的单位置代价分别为1/400；它不表示化学或语义距离。此性质不单独证明它造成所有训练或生成失败。 |
| 原解码会放大局部PAD错误 | H1/H2固定分数上的firstPAD→J把四模式丢失真实残基118/272/267/242降至15/16/13/22。是同分数解码干预证据；不是多数提前结束对象全部修好。 |
| 固定表示读出存在局部可修复性 | H2 CE+J通过局部内容/PAD/长度保护，但val mean仅274/701残基正确、1/41整串正确，随机三模式整串0，train四模式整串也0。H1容量/优化混杂与H2同357参数比较的ridge/尺度边界不能抹去。 |
| 隐表示完全无内容或条件后验肯定未坍塌 | 均未证。H0匹配末端和长度的置换损伤内容，但g本身几乎标识序列，不能排除q接近p(z|g)；14/16活跃维度也非条件互信息证据。H3两个已充分优化的固定特征头失败只否定预锁候选门，不证明所有非线性函数或端到端训练都无效。 |
| 重建端进展已迁移成一致生成改善 | H4不支持：H2合法1–48为95/96、5–48为91/96；MMD²对train/val五升一降，同时val二肽JS/L1六降。生成观察混合；G4 VERIFIED只是完整描述覆盖。 |
| DDPM潜变量/hidden处于OOD，且它是生成失败根因 | 尚为假说。H4未建立train支持集、校准距离阈值或控制其他因素的分布匹配干预。生成MMD变差、重建改善而生成不佳、latent统计差异均不足以单独定因。 |
| 改成CE就能修复端到端和生物效能 | 尚为假说。新表示、非凸优化、KL权衡和DDPM建模都可能限制结果；没有新增真实活性/安全结果。 |

已有标准类别损失、one-hot回归、合法前缀J、条件AR、VAE和DDPM属于成熟部件。借鉴这些部件是修复/对照，不自动构成新算法。PepVAE的一手文献及可迁移范围由指定文献审阅者另核，本意见不将其当已复现、已证胜出或本轮新增实验臂。

## 2. 最小臂与原方法保留

用 **c** 表示FREE/AMD terminal元数据，避免与原代码的 **h（9维全局描述符）** 混淆；g为逐残基3维描述符。

| 臂 | 本轮角色 | 训练与生成约束 |
|---|---|---|
| O0 原scalar+原DDPM | 冻结历史锚点 | 保留原loss、scaler/abs、warmup、checkpoint及负结果；主生成参照只取原terminal-only DDPM的FREE16+AMD16，不能拿带源序列g的flow补强效果。旧预算/开发过程不同，O0不是新共同成本匹配基线。 |
| O1 H4冻结H2+J+原DDPM | 冻结局部修复锚点 | 同样只取其terminal-only DDPM32条；保留FREE空串和资格变化，不重新挑样/重训。 |
| E-CE 端到端21类CE | 事前主候选 | fresh初始化，保留原g/h训练架构、latent16、WN/flow、预处理、数据边界；全VAE参数按新协议训练，随后以自身encoder重新编码train，并训练自身terminal-only DDPM。 |
| E-MSE 同容量raw one-hot MSE | 损失形式控制 | 与E-CE完全相同21头/357末层参数、上游初始化、优化器/日程/批顺序和预定随机流；只改变已明示的重建损失。同样单独重编码和训练匹配DDPM，不能复用E-CE或原DDPM。 |
| AR 单一规范terminal-only序列模型 | 新完整方法竞争者 | 从头拟合，相同train279与c信息，生成只读c、BOS及自身已生成前缀。选择一个实现/配置并冻结，不能LSTM/GRU/分层/共享模型跑完再择优。 |

CE主候选身份在看H5结果前锁定；若MSE更好，报告对照结果并否证相应CE主张，不自动换主候选。两个新VAE末层同为357参数，若原架构全保留则全网各1,681,549参数（原1,681,209）；由作者构建后再核计数，不用这个静态计数宣称吞吐相同。

原scalar若不新训，只能作为历史锚点。若要声称“在当前相同预算下战胜原方法”，需另有预先授权的fresh scalar完整管线臂；这不是本意见默许的第四个新方法。旧模型不能被新稿悄悄替换或将旧失败记为已修复。

## 3. 损失/尺度：必须先锁住的数学合同

建议以共同位置权重覆盖全部48格，PAD作为第21类；不得把预测失败或PAD目标偷偷从某一臂的分母去掉。两臂raw scores均为s[b,t,k]，共同J直接从各自scores对49个合法AA前缀/PAD后缀求最大值，长度相同分时选最短；不使用真L。CE下为合法序列联合MAP，raw one-hot MSE下为到合法one-hot序列的欧氏投影。MSE是未softmax实值回归，不冒称概率Brier；若改为softmax Brier，已是另一损失合同，不能临时替换。

推荐明确写出：

- R_CE = −Σ[b,t] log softmax(s[b,t])[y[b,t]] / (B×48)。
- R_MSE = Σ[b,t,k] (s[b,t,k]−onehot(y[b,t])[k])² / (B×48)，对21坐标求和，不能由库默认额外除21。
- K = Σ[b] E_q[log q(z_b|x_b,g_b,h_b) − log p(z_b|g_b)] / (B×48)，保持原flow密度和logdet定义。若实现返回的是旧K_old=Σ(logq−logp)/16，只有核实相同求和域后才可用16K_old/(B×48)换算；不能凭变量名推断。
- L = R + βK。建议以明确的共同固定β=1作为条件ELBO/固定尺度对照的可审查起点；这只是候选设置，不是已证最优β，也不是本意见签发运行值。作者/root须在正式协议中选择并冻结最终β或完整schedule。

原目标是全48格scalar平方和除以当批非PAD数，再加随batch大小变化的旧KL。因此改成上述共同规范化本身也是相对原方法的变化，必须披露。E-CE/E-MSE的同β不保证相同有效正则强度或相同梯度尺度；允许得出的结论仅是“该固定归一化、β、优化器和预算下的目标形式对照”，不是损失无条件优劣。禁止看val后为一臂调β、学习率、温度、class权重或loss倍率。

在已授权训练日志内记录R、K、βK、总loss、学习率、有效token/位置、有限性和实际梯度裁剪情况。若额外量测分项梯度范数，所需backward次数须事前计入成本；不另开未锁定的校准搜索。原warmup在1000步才接近目标学习率的事实必须继承或明确共同改动，不能用短预算失败推断架构无能力。非凸端到端优化不能套用H2凸头的强凸差界作为全局最优证书。

## 4. AR接口与公平信息边界

为避免同时试多个AR，正式协议应在代码可复核后选定一个配置。优先最小实现可为**单个terminal条件LSTM/GRU**，固定一种单元；若为尊重既有LSTM_peptides适配而采用两个terminal分层子模型，则明确这是唯一AR方法，两个模型参数和训练/采样成本相加。两种结构是待作者/root选择的互斥实现，不同时跑、不按val选择。本意见不指定隐藏宽度/层数或新seed。

训练teacher forcing严格右移：输入BOS,c及真实前缀，目标下一AA或首PAD；首PAD之后不再属于生成路径，其训练尾部掩码须预锁。生成不提供真实前缀、真长度、源对象g/h、近邻prototype或val对象。上限48；抽到PAD结束，48AA未抽到PAD可表示长度48；空串/短串保留，禁止最低长度拒采或失败补样。训练/采样支持必须一致，不能边训练类别NLL边在采样期无说明截断top-k/温度搜索或禁PAD。

建议AR预锁temperature=1的完整类别分布采样（若采用其他值，必须事前固定且算一个选择机会）。AR没有理由强套非自回归J；使用各方法标准、明确锁定的解码，只允许端到端完整方法比较，不能由AR对比单独归因J。AR teacher-forced NLL、VAE重建和DDPM噪声loss不可横向排名。

E两臂训练可由各自train序列计算g/h，但val不能进入scaler、描述符统计、训练缓存、DDPM或AR训练。生成三种新方法都只接受c；保存入口审计证明未带源对象信息。使用train序列的确定性g/h是训练算法的一部分，不能因此声称与AR架构相同；信息公平指相同可用数据和生成期条件，不是强迫同参数量。c是末端元数据，不是抗菌标签，序列字符串本身也不验证末端化学身份。

## 5. 预算、选择机会与保存

新生成暂按每方法FREE16+AMD16=32请求讨论：E-CE/DDPM、E-MSE/DDPM、AR若全执行，共96个新上游请求。这里不扩回每方法三来源96，也不新增flow/aggregate臂。沿用已经存在的固定seed合同或由root明确绑定；本意见不选新seed、不追加重复运行。不同模型同数值seed不意味着逐对象配对潜变量或共同噪声效应，不能套H4共享latent的因果语言。

同容量损失对照优先共享固定更新/token计划和optimizer日程，并记录实际耗时差异；训练预算不足时不得让某臂偷偷延长。完整方法公平另用共同**总训练成本上限**：E各自的VAE+重新编码+DDPM+任何新拟合，比较AR全部训练成本；分层AR两模型合计。共同生成32请求的实际调用、时间/内存单列，再报告训练+生成总成本。若宣称端到端总资源优势，必须有对应共同总预算，不能只约束训练或只报H2头成本。

具体秒数/更新数尚无本意见授权。作者应据现有CPU实测冻结每方法总预算、VAE/DDPM分配、warmup与末点；不能用“每个组件1000步”冒充相同总成本。CPU单线程且尽量串行计时；若并发竞争资源必须记录，否则墙钟不具可比性。到达上限的在途调用/终末保全、超时状态须统一，不假装硬截止已实测。所有臂保存初值/末点/optimizer/RNG/源码hash、实际训练对象/token、原始生成scores或step概率、latent/hidden、全请求输出与失败账本。

每个新方法一个事前配置、一个固定终点；无best-val checkpoint、seed搜索、额外采样后筛选或胜者追加预算。AR也获得同一明确开发规则，不能故意少训而称强baseline已败。H0–H4已对该队列提供大量设计反馈，历史选择机会无法追溯抹平：分列“本轮运行成本”和“累计开发/选择历史”，不要声称新协议已消除全部选择偏差。控制臂研究成本计入本次总研究账，不伪装成零成本；独立部署成本可另列。

## 6. 建议的可证伪判定（正式协议须采纳或明确替换）

先分别锁工程门、机制比较和完整方法比较，禁止跑后改成只叙述有利指标。以下是**有界pilot经验门建议**，不是显著性检验或论文充分性门。

1. **工程门E**：数据/源码/初始化身份、零test、无非法真长度/源条件输入、实际预算、有限性和全attempt保存均通过；失败即记具体工程/预算未完成，其科学比较标为不可判或未完成，不把失败样本删去。
2. **损失比较L（E-CE vs E-MSE）**：两臂相同容量、初值、数据次序、目标归一化/KL及优化合同；按事前固定的同一重建模式集合（可继承mean和原三个posterior模式，不添加新模式/seed）报告train与dev。建议强信号门为每个dev模式rendered非PAD micro与macro严格提高、长度MAE不升、整串exact不降；任何项未满足则“未通过L”。同时保留截断后token不进入rendered的边界。单一模式/终端的收益不升级全局结论；不比较不同loss的裸数值高低。
3. **生成比较G（预选E-CE/DDPM vs AR）**：每方法32请求完整，分别FREE/AMD；建议清晰质量比较首先要求两方法全部合法1–48（否则仍完整描述，但G不通过）；两terminal开发参考421-feature MMD²均严格降低，同时合法5–48数不降、exact-train-copy数不升、组内合法unique数不降。将AA/二肽熵与train参考的绝对差作为预定保护项，均不得比AR更大，避免只优化均值距离却忽略明显集中。所有JS/L1/KS/entropy/NN/copy字段仍全报，NN近不能自动判好坏。此零容忍经验门严而清楚，不新增“提高5%”等事后阈值；若作者认为某保护项不适合，必须在新数据前改并解释。
4. **原方法参照O**：同时列O0/O1在同terminal-DDPM任务的全部既有结果与成本差异。新CE即使相对旧输出改善，也只能称历史锚点比较；要升级共同成本下“修复原方法”，需另行真实匹配O0训练臂。不能将E-MSE没过L或AR没跑充分隐藏。

若G通过，仅是此固定seed、16请求/terminal、已复用dev的经验门通过；不宣称统计优越、活性或可投稿。若不通过，明确该候选在指定门下未建立完整方法优势；不能换MSE/RFF/flow作主候选，也不能说全部模型/全部分布都失败。两个新VAE和匹配DDPM的执行范围/阶段停止规则必须预先一致；不因先见某臂dev结果就只生成另一臂。数值故障可停止该臂并保留，其他授权臂可继续。

## 7. 如何区分目标限制与生成分布假说

| H5结果 | 可支持的有限解释 | 仍不能推出 |
|---|---|---|
| CE相对同容量MSE在重建门通过且生成也更好 | 固定尺度/训练合同下CE整条训练路线有利；局部读出事实扩展到本次新表示和匹配DDPM | CE是唯一原因、最优β、任意数据/seed都优越 |
| 两个新头重建都更好、生成均未过G | 端到端表示的重建改善不足以保证当前完整生成管线优势 | 已证明DDPM latent OOD或条件坍塌是根因 |
| CE与MSE重建都未改善 | 此预算/优化/架构组合未修复相应重建问题 | g/h架构理论无效、hidden无信息、类别目标不适合所有情况 |
| 与AR比较G不通过 | 当前完整latent→DDPM路线的额外复杂度尚无本门下优势 | AR全局最优、所有diffusion无效 |

可以在冻结协议内保存训练后验参数、DDPM生成参数、latent/hidden及其train-only标准化的既定摘要，供读出支持范围诊断；不得临时增加生成来源或额外seed。距离/覆盖摘要只可称分布差异观察，未校准不可标“OOD率”，更不构成因果干预。若要单独验证分布不匹配因果，需要下一份独立预锁、同读出同信息且只改变潜变量来源的实验；本意见不擅自启动这一额外臂。
