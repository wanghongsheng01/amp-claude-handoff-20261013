# 原生 MIC 标签开发性准入：独立科学复核

**裁定：可以研究原生同单位的报告 MIC；不要求先全部换成 µM。** 最窄合理任务是：在本次已经暴露的 DBAASP 缓存内，分别预测 E. coli 的数据库原生 `log10(MIC, µg/ml)` 或 `log10(MIC, µM)` 报告值。两单位分开建模、比较，不换算、不混池。这里的“原生”指缓存字段，并未核实原论文是否本来使用该单位；目标是报告端点的统计预测，不是统一实验条件下的纯肽摩尔效力。

| 字段或条件 | 本任务的科学作用与准入处理 |
|---|---|
| MIC 定义、E. coli 归属、原值与单位 | 硬要求。不能把 MBC、归一化辅助数值或其他病原端点混为标签；只用有限正值的已识别单位。 |
| 点值、`>`/`≥`/`<`/`≤` | 保留语义。原 Witten MSE 仅用于明确点值；单侧界保留供删失方法或界违背评估，绝不可当点值。范围与 ± 未知时不猜其含义。点值子集的结果仅适用于可报告点值的子集，有选择偏差。 |
| 精确菌株、培养基、CFU、pH、盐与离子强度 | 对“固定测定条件”的解释是必要信息；对本次异质报告值预测可为缺失协变量。保留缺失，报告分层、来源偏差和敏感性；不能填成默认实验条件，也不能把多菌株汇总当作多个独立观测。 |
| 末端、已知修饰、二硫键/环化 | 未知末端不等于 Free。普通 CNN 只观察序列，不能区分未编码化学形态；这限制预测的信息和解释，不自动否定其作为同一序列特征基线。保留化学分层，不宣称化学实体已完整编码。 |
| 分子量、盐型、纯度、材料计量基准 | 对质量到母体摩尔浓度的可靠换算是硬要求；对原生质量报告标签不是硬要求。原生 µM 同样只是数据库报告，不能因其单位自动宣称物料基准已验证。 |
| 真正混合物、单肽归属不明、身份真实冲突 | 不得把多组分总效应冒作某个单肽标签。保留原行，归属未解者暂挂最窄主集；结构验证器未匹配不等于已证明身份冲突。 |
| 序列与来源 | 原 Witten 接口限原始大写 20-AA、长度 1–99；不可把 D 型小写静默转成 L 型。保留原始 ID、化学指纹、来源与缓存哈希；索引可追溯不等于逐条论文实验已经核验。 |
| 重复、家族、来源与隔离 | 真实重复全部保留，不猜平均值；记录、肽、家族和来源合并组分别计数。所有相关记录须同组，组权重/验证先冻结，不能按行随机划分。既有 test37 封存和保护性隔离要求不变。 |

**建议主候选集**采用上述可解析原单位点/单侧界及严格 Witten 特征域；ID16、36、1783 的备注提示其为 dimer/two-peptide 的组成部分，无法仅凭缓存判定每项 MIC 测了单链还是组合。三者暂挂单肽归属，保留包含它们的敏感性计数，不能称为已证混合物。16/36 仅有未明范围，因此实际主点/界集只减少 ID1783 的 4 个质量单位点行。

独立重算主候选为 **102 行、54 个唯一 ID、33 个操作性序列家族、14 个来源合并组**。µg/ml：点值 **46 行/33 ID/17 家族/10 来源组**，含界 **58/42/26/10**；µM：点值 **39/13/8/7**，含界 **44/14/9/7**。跨单位共享 ID/家族，不能相加称独立 N。若不暂挂组成肽备注，Witten 候选为 106 行/55 ID/34 家族/14 来源组；未限制普通 CNN 字符的可解析报告核心为 125 行/58 ID/37 家族/15 来源组。所有计数是缓存中的操作性去重/分组数量，不是已证明生物学独立的样本量。

**可检验**：冻结相同标签、表示、来源/家族分组和预算后，简单基线与 CNN 能否拟合或预测这一小缓存中的报告端点；后续可把删失处理设为单一受控差异。**不能检验**：标准化条件下的因果效力、未见病原/实验室外推、生成肽的活性、H5 的独立确认、新颖性或投稿就绪。183k CNN 对此样本量很大，任何比较须同时有简单基线并报告来源/家族有效数量；单次低误差不足以证明优势。

科学适用性为 **YES（开发性报告值任务）**，不是本轮启动训练的授权或已完成隔离的证明。本轮仅离线计数；无新采集、网络、模型执行、训练或 train/dev/test 读取。当前结果不能再被“计量基准未知”一条规则整体归零，但进入受保护 AMP H5 训练前仍须冻结开发划分/预算并取得既有不透明隔离回执；test37 不开放。
