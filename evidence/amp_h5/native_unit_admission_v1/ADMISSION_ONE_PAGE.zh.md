# AMP H5 原生单位监督任务：科学准入复核

**裁定：现有原生单位标签可用于开发性 baseline，不必先全部换成 µM。** “86 行不能可靠换算为已验证母体摩尔浓度”仍成立；由此推出“全部不能研究”过度保守。“原生”指缓存原单位，未逐条核实原论文是否同单位。本轮仅复核与计数，不采集、不训练。

**最窄主任务：**在既有缓存中，用原始大写 20-AA、长度 1–99 的序列特征，预测来源报告的 E. coli MIC **原生 µg/ml 正点值的 log10**，与相同数据/分组的简单常数或序列组成控制比较。估计对象仅为该点报告子集的标签关联。原生 µM 完全分开作为次任务；不转换、不混池，不称其计量已经重新验证。修饰及缺失注释保留，普通 Witten CNN 无法区分同序列不同化学形式。

| 字段/问题 | 必需性与处理 |
|---|---|
| MIC、物种、单位、数值、来源归属 | **硬要求**：确为记录所报告的 MIC、E. coli、已知原生单位、正数值且可追溯。缓存来源映射不等于重读原论文验证。 |
| 删失、范围、± | **硬要求保留语义**：单侧界不能冒作点值；范围/±未核实者保留待定。点值任务只解释点报告子集；删失行可另冻结删失感知任务。 |
| 精确菌株、培养基、CFU、pH、盐/离子强度 | **缺失协变量与敏感性分层**，不是异质报告预测的完整性门槛；不能由此声称固定条件效力或条件因果作用。 |
| 末端、修饰、立体化学、SMILES/MW | 未知末端不等于 Free；图验证器未处理的互变异构不等于身份错误。保留化学注释、缺失标记及分层；禁止把 D 残基自动大写后称化学等同。模型表示不足须明示。 |
| 盐型、纯度、净肽量、材料计量基准 | 对**质量→摩尔换算及纯母体效力解释**是硬要求；对已报告同单位质量 MIC 不是硬排除。未知不修正、不当已知。 |
| 多组分/单肽归属 | 真混合物不能冒作单肽标签。ID16/36/1783 有“二聚体/双肽组成部分”备注：归属待定、主集暂挂，保留原行与更宽敏感性计数；不称已证混合物。 |
| 重复、来源、测试隔离 | 保留真实记录及活动 ID，不擅自平均/删除；同条件/来源不等于独立重复。后续整组分割并控制多记录权重；测试隔离保持硬要求，test37 封存。 |
