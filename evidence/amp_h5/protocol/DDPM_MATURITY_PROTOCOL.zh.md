# AMP H5 固定表示的 DDPM 数值可行性诊断

本实验是 VAE_FEASIBILITY_HOLD 后的单独工程诊断，不是 H5 正式方法比较，也不替换或删除失败 smoke。H4 已保存末步路径核验通过，但未验证新权重或完整链稳定性。原 FORMAL_PLAN 仍不获执行许可。

唯一训练输入为 CE smoke 的 train279 后验参数缓存及末端标签，固定该 20 步 VAE 的表示，不再调用 encoder、decoder，不读取 train/dev/test CSV。数据及源码、参数、运行脚本和入口计划均以 SHA256 绑定。fresh DDPM，seed322，原 epsilon-MSE、原 999 时刻线性噪声表、原 AdamW/OneCycle 与 EMA 规则均不变；OneCycle 总步数预定 1000。

仅训练一条 1000 更新轨迹，保存第20和第1000步权重。全部训练完成后才执行四个预定采样请求：两个检查点分别 FREE1、AMD1，种子422/423。各检查点复用相同初始噪声、每一步逆扩散噪声和末端重参数化噪声，记录这些随机量的摘要以核对配对。禁止筛选、重试、补采、截断或替换数值，不导出肽序列或计算生成质量。各逆扩散时刻的状态和预测必须有限；末态 sigma 必须有限且严格正，z 必须有限。所有请求，包括失败，完整记账。

训练硬预算1020秒，四请求生成合计240秒；串行、CPU单线程，外层总超时1380秒。未到1000、非有限训练或超时均保留并判对应执行失败，不追加预算。训练完成后即使第20步采样失败，也执行预定第1000步请求；禁止按质量提前停止或改配置。

解释规则在结果前固定：若第20步失败而第1000步两末端数值成功，说明在此固定表示、种子和1000步学习率轨迹中，继续训练改善了被测数值采样可行性。不能据此断言旧 smoke 的唯一根因是欠训练，因为旧 smoke 的 OneCycle 总步数为20；也不能外推新 VAE1000 表示、其他种子或16请求批次必然稳定。两个检查点都成功、都失败或混合结果照实报告；数值成功不等于接近训练分布、序列质量、泛化、活性或算法创新。

报告必须同时呈现训练缓存和生成末态 mu/logsigma/sigma/z 的尺度，不把 finite 等同于合理尺度。只有本诊断完成、独立后审及尺度判断以后，才可为预先选定 CE 臂签发单独有限训练回执；不得自动放行三臂。任何稳定参数化或范围约束必须成为另一个明确版本、有数学理由、适用于相关对照臂，不能暗中 clip。

该额外诊断成本与适应性决策在最终报告单列，不能冒充四臂等计算或无额外开发。test37、H0–H4与稿件仍只读封存；无上传、凭据操作或投稿。
