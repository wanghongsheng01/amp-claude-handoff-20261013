# AMP H5：原生单位开发性 baseline v1

本包执行一次已冻结的开发性比较：原生 µg/ml 与 µM 分开，使用缓存所报告的 MIC 正点值，不换算单位、不将删失/范围/±当作精确点值。它检验当前数据管道及固定基线配置的开发性表现，不能作为独立确认、纯母体效力、创新或抗菌肽生成效果的证据。

## 数据与折划分

严格复用 `native_unit_admission_v1/ROW_ADMISSION.jsonl` 中科学复核允许的原始大写20-AA、长度1–99的点报告：质量单位46行/33肽/17临时家族/10来源合并组；摩尔单位39行/13肽/8家族/7来源合并组。归属待定的组成链备注仍暂挂。原始标签、单位、化学注释、测定条件与缺失值保存在 `DATA.jsonl`；缺失项没有虚构填补，也没有完整病例删除。原生指缓存原单位，不代表逐条重读原论文完成计量验证。

分别留出一个既有来源–家族合并组，共10+7折。这些组在此前全部75个肽上形成，未为本轮样本量重新聚类。每折检查肽ID、精确序列、化学指纹、临时家族、来源合并组和已知论文key无训练/验证重叠。该检查只是已有注释范围内的分组隔离，不是更广泛同源、未记录别名或原始H5 test37污染清除证明。

- µg/ml 验证折行数：1、13、4、3、1、3、5、2、4、10；训练折33–45行。
- µM 验证折行数：2、2、25、5、1、3、1；最大验证折对应训练仅14行。其余训练34–38行。

不拆大组、不硬凑均衡折，实际成员/分母在 `FOLDS.json`。这些已暴露缓存不是盲测；无原始train/dev/test文件、原27湿实验或稿件参与。本包权重标记为开发专用，不应未经隔离审查转入受保护的原H5评价流程。

## 冻结模型与评分

三个模型使用完全相同的训练折及层级权重：训练来源组等权、组内肽等权、肽内记录等权，权重总和为1。同肽多条真实记录仍保留，不擅自平均为虚构观测。

1. 训练折加权均值常数。
2. 20-AA组成比例＋log长度的线性ridge，训练折加权均值/标准差标准化，固定alpha=1，目标为加权平均MSE＋alpha×系数平方和，截距不惩罚；不调参。
3. 已审计的183,069参数Witten CNN架构等价PyTorch实现，seed1729；每折同种子重新初始化，全训练折加权MSE，全批固定100次更新；Keras式Adam lr0.001/epsilon-hat1e-7。标签减去训练折加权均值，预测时加回；中心值不使用验证标签。无早停、验证择优、种子或超参数搜索。加权全批与100步是明确的本地开发训练配置，不是原论文训练过程或性能复现。

主指标为 **来源组内先肽等权、肽内记录等权，再来源组等权的 MAE(log10原单位)**。辅助RMSE是同一层级平均MSE开方，不是各折RMSE的平均。另给行等权与肽等权敏感性指标。两单位分别报告，不能混合或把重叠组相加为独立N。不作显著性、统计功效或广泛外推的结论。

`run/PREDICTIONS.jsonl`、`.csv` 保存255条（85行×3模型）折外预测及原标签/缺失字段；`run/RESULT.json` 保存每单位与每折完整指标。每折receipt含训练成员、精确训练权重、中心值、ridge参数、100步训练损失和checkpoint哈希。验证仅在固定终点后预测，未用于选训练终点。

## 工程与资源边界

`FREEZE.json` 在自然运行前绑定数据/代码/划分/配置，`independent/SIGNED_PREAUDIT.json` 先验签署，独立审核不导入模型或运行训练。CPU单线程、BLAS单线程、nice+10，串行17折，固定1700次CNN更新，600秒/1.5GB上限，无新依赖/网络/权重下载。

首次沙箱启动在 `os.nice(+10)` 被阻止，发生模型构建之前。`attempt1_startup_failed/` 保留STARTED和原始错误，独立确认0模型更新/0预测。自动审批允许以同一冻结命令降低自身进程优先级后执行；没有修改数据、代码、种子、超参数或择优重跑。详见 `STARTUP_REPAIR.json` 与 `independent/STARTUP_REPAIR_AUDIT.json`。

最终状态及指标见 `DELIVERY.json` 和独立 `independent/RESULT_AUDIT.json`。所有失败、负向折和负向模型结果均保留；BACKUP_BLOCKED。
